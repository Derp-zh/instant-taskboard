# 即时任务看板 0.9.22 使用说明

适用于 Windows 10 2004 或更新版本、Windows 11，64 位。运行包自带 .NET。

## 开始与升级

1. 下载 `instant-taskboard-0.9.22-win-x64.zip`，完整解压到新目录，运行“即时任务看板.exe”；保留目录内全部文件。
2. 升级前从旧版托盘菜单退出看板。程序与任务数据分开保存，升级不会主动迁移或清空数据。不需要退出 Codex。
3. 点击悬浮球展开六个独立列表；灵感库可以直接输入，其他列表的新建入口可填写完整任务。默认快捷键为 Ctrl+~。
4. 首次 AI 初始化提示可选“稍后配置”，不影响普通使用，后续不会每次启动反复提示。

## 阶段与列表

- 在新建或编辑窗口中，点击阶段名称右侧圆形 X 删除阶段。编辑内的删除需保存任务才正式提交；取消保留原任务。
- 至少保留一个阶段，也必须保留一个运行中的阶段。要删除唯一运行阶段，先将另一个阶段设为运行；禁止删除时显示提示气泡。
- 六个内置列表均可改名、隐藏和重新显示，不能删除。新增的自定义列表清空任务和非空草稿后可删除。
- 旧版本曾删除的“完善中、暂搁置、已完成”会恢复为隐藏，保留原名称；不会强制弹出窗口。
- 卡片可拖动排序/移列，搜索涵盖任务名称与阶段详情。完成仍由用户手动确认；归档可以恢复。

## 设置与提醒

- 设置保留主设置、窗口、监听、归档、数据与备份、AI平台接入、飞书接入七项导航。相关控件按用途分组，按钮可换行。
- 设置沿用即时生效与自动保存；右上“保存设置”可立即保存并显示结果。修改全局快捷键仍需点“应用快捷键”。
- 可调整窗口大小/透明度、球右边缘吸附、自启、提醒和通知提示音。监听默认关闭，通知声音与 Codex 移列是不同功能。
- 球从边缘弹出时，红点完全消失和数字出现由同一动画帧更新。真实显示器上的悬停流畅度尚未实机验收。

## Codex 初始化与关联聊天

用户需先安装 Codex。目前只有 Codex 提供实际接入，其他平台标签不等于已连接。

1. 在首次提示点击“一键初始化”，或从“设置 → AI平台接入 → 初始化AI平台配置”进入。
2. 程序自动查找桌面端与 CLI，并优先沿用已有有效路径。找不到时可分别手动选择；桌面程序用于打开 Codex，CLI 用于读取聊天目录，两者不能混用。
3. 查看每项检查和下一步。只有聊天目录与完整观察源本次均通过才显示“配置完成·连接已准备好”。没有绑定聊天时，“具体聊天未验证”会单独显示。
4. 若提示需重新打开 Codex，请先自行保存工作并退出 Codex，再主动确认界面中的打开操作；看板不会擅自退出、重启或打断 Codex。无需手工运行项目脚本或填写环境变量。
5. 初始化不选择、创建或接管聊天，也不发送测试消息、回答问题或批准操作。具体已有聊天仍由用户在任务阶段内搜索和选择。

**兼容限制：** 当前固定观察兼容范围为 Codex 桌面 26.1013.4894.0，且需通过身份、模块哈希和连接检查。已只读核验的 26.1016.6573.0 结构已变，仍显示“当前版本暂不兼容/待完成”。目录可读不代表该版本可以完整监测；不自动降级、不修改安装文件。

兼容并已连接时：真实执行进入进行中；问题、批准等待、整轮结束/失败/停止进入待操作；回答或批准本身不算恢复，需实际继续执行。多阶段等待优先，断线和未知状态不清除已确认等待。真实整轮失败、额度耗尽停止仍待原桌面专项验收。

## 本机数据与备份

默认任务目录 `%LOCALAPPDATA%/InstantTaskboard/data`，配置目录 `%LOCALAPPDATA%/InstantTaskboard/config`，均可在设置中调整。搬动程序目录不会自动带走系统数据；换电脑请同时备份实际任务与配置目录。设置中的“配置备份”只包含设置，不包含任务和草稿。

## 验证边界

0.9.22 已完成隔离核心规则/存储 334 条、新增离屏控件/真实保存链/确定性动画帧 38 条、初始化回归 37 条、数据配置整合 17 条。数量不代表真实桌面场景数。未进行物理鼠标点选/悬停、真实显示器逐帧像素及多屏混合 DPI 验收；旧球离屏位移动画的已知失败边界保留。
