# 拖动绑定独立测试版 r2

本地测试版已经完成原 Codex 的真实拖动绑定，不计入正式版本，未上传 GitHub。

## 启动与操作

双击 `release/即时任务看板-拖动绑定测试-r2-20261022/启动拖动绑定测试.cmd`，也可以直接打开包内 `Taskboard.exe`。自动使用包内 `preview-data`，首次生成一张两阶段示例卡片；测试任务与正式任务、配置相互独立。

1. 在“完善中”的示例卡片上，按住阶段右侧“未绑定”或已有会话名称拖动。
2. 拖出来源列表窗口，其他原可见列表临时隐藏，名称跟随鼠标。
3. 放到 Codex 侧栏的一条会话，或当前聊天正文区域，松开鼠标。松开后稍等，会话名称更新并保存绑定；其他列表恢复。

侧栏会话可以直接绑定，不必先打开它。主聊天区域绑定当前显示的会话。Esc 或鼠标右键取消，单击名称不改绑定。退出请用测试版托盘菜单。

## 实际绑定方式

松开后短暂展开目标会话的“复制→复制深度链接”菜单，取得原 Codex 返回的真实会话编号，再保存到来源阶段。名称仅用于显示，不要求它能在会话目录匹配。Codex 菜单可能短暂出现，读取完成后恢复原剪贴板；拖动不会投放文件、插入文字或发送消息，不需要重启 Codex。

若目标已变化、正在使用菜单或没有取得有效链接，保留原绑定并显示原因。测试版仍属探索实现，建议松开后等结果提示，再操作鼠标或剪贴板。

- 原 Codex **26.1016.8120.0** 上，真实鼠标拖动三次均绑定并落盘：侧栏当前会话、侧栏另一条未打开的会话、当前聊天正文。两个不同会话编号均与独立菜单读取核对一致；改绑另一条侧栏会话没有切换当前聊天。
- **34 项实机检查通过**：包含其他五列隐藏/六列恢复、只改来源阶段、准确编号写入实际 `board.json`、文字及 HTML 剪贴板恢复、隔离看板重开后名称和编号保持。测试结束后原剪贴板、鼠标位置及前台窗口回读恢复。原始结果：`test-output/drag-binding-real-03/real-binding-report.json`。
- **40 项最终测试包隔离检查通过**：链接解析、过期绑定、改绑代次和旧等待、其他阶段、编辑合并、撤销、文件回读、名称布局及文字外空白命中、子宿主来源、隐藏/恢复及主动收起。属于合成/离屏检查，与上述真实操作分开记录。结果：`test-output/drag-binding-r2-verified-build/drag-binding-report.json`。
- 文字/HTML 多格式缓存独立检查通过；旧 OLE 代理失效问题已修正。初次实机测试曾因游戏/窗口覆盖按下点安全停止；正文菜单首次因接口类型不符失败，改用实际的展开接口后，最终三种真实路径通过。失败记录保留，不计入通过数。

本轮使用显式隔离 `--data-dir`，未操作正式数据、配置、自启或 preserved-data；没有重启原 Codex、发送消息或执行批准。
