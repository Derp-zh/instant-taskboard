# 即时任务看板 0.9.20

2026-10-21，Windows x64 完整便携版。

- 修复独立列表任务卡片阶段名称行的空间分配：从右至左为阶段状态图标、绑定会话名称、靠左的阶段名称气泡。
- 会话名称按最新澄清改为实际字体3至5个中文字符宽；不足3个中文字宽按3个占位，超过5个中文字宽滚动。此前按6至10个英文M字宽的实现偏宽，已在widthfix修正版中修正。阶段名称没有字符最小宽度，短名称自然显示，长名称使用扣除右侧控件及原有间距后的全部余宽，溢出滚动。
- 缩窄或拉宽同一卡片时重新计算阶段可用空间；极窄时裁掉放不下的气泡，不再让内边距撑入会话栏。会话栏保持图标左侧的右锚点，不被向右顶入图标。
- 保留原文字滚动速度及停顿、单阶段无状态图标、灵感库会话显示例外，以及卡片原有操作。

只更新显示布局，沿用0.9.19的Codex观察模式及其验收边界。完整解压本版后运行“即时任务看板.exe”；旧版正在运行时请自行从托盘退出后再启动新版。正式数据、自启和当前Codex不由更新过程操作。
