## 0.7 输入、卡片与拖动交付

先在PRD第20节、任务清单和索引同步U27至U31；用户确认只压缩卡片内部纵向空白为3/5。TaskCard上下内边距6.6、文字上下留白2.4；分隔线和胶囊纵向留白同比缩减，字体、横向间距、卡片间距8及新建入口保持。

搜索框的Border和内部ScrollViewer重复扣除Padding，固定38高度内的文字视口为0；现在Padding仅由内容宿主计算一次，文字视口18，足够显示13号文字与光标。RoundedInput通过圆角几何同时裁绘与命中，左右留白内点击直接聚焦并定位光标；形状之外不触发。SurfaceContentRoot及GlassContentHost转发子表面的UI Automation根，使真实输入和按钮可以被Windows准确定位，保留独立字符队列。

OptionMenuToggle将菜单放在按钮下方，保持触发框裸露；监听IsOpen变化时立即记录关闭手势，避免等淡出结束的Closed事件后才处理，导致同次点击重新打开。真实鼠标分别检查AI与优先级的开、关、再开；保留多选、外部关闭和窗口收起时关闭弹层。销毁编辑视图时解除全局输入订阅。

CardDragSession在开始时按源屏幕DPI生成一次卡片图像，透明、鼠标穿透且不激活的临时窗口跟随物理指针，始终保持球在其上。源卡片只在视图中移除；目标列用按该列宽度和展示规则排布的副本作为虚线占位，其他卡片和计数预览插入后的状态。相同落点不重复重排，自动滚动限速；松手提交一次移动，取消恢复视图，释放计时器和跟随窗口。正式任务和撤销记录在预览中保持原值。

## 0.8.1 界面、Codex与动态列表完整包

按用户确认实施U32至U37、A50至A55、T52至T58。列表配置使用稳定身份与内置角色，旧六列数据自动兼容。名称不驱动业务；灵感库、进行中、待操作可隐藏和改名，不可删除；正式任务、非空草稿或编辑原值仍引用的列表不能删除。删除空列保留身份，撤销任务删除或移动时恢复原列。隐藏不计入显示数量；整体布局和缩放只涉及可见列，零列情况下不计算无效外框。设置导入保留现有任务所需的列表定义，不修改任务数据。

CodexRpc和CodexObserver移植codex_probe的只读通信及规则。RPC允许方法白名单，IO在后台执行，准确会话编号、关联代次、来源批次、轮次与事件顺序分别校验；监听不替用户回答、批准、执行或恢复会话。编辑中选择现有聊天或粘贴编号，保存才改变正式关联。本机历史目录可读，当前原桌面实时桥接未连通；明确待确认，不把历史状态当成运行。只有可信事件让进行中/待操作互相流转，时间红点由用户操作清除，失败/中断单独显示。配置备份只含程序路径和本机端点，具体会话关联属任务数据。[官方只读会话接口](https://learn.chatgpt.com/docs/app-server)支持本轮通信边界。

圆球用Ellipse及CompositionEllipseGeometry直接绘制，保留40%透明度；不使用整数HRGN切圆。托盘和应用图标使用同一矢量图案生成的多尺寸ICO。原生圆外鼠标命中返回透明，最终桌面像素另外验证圆外无底板。预览范围使用物理坐标，覆盖球、小窗口及上下连接通道；区外才延迟收起。
