# 0.9.30 Codex接入取舍与设置整理

## Codex接入

- 保留初始化、安装路径发现与升级修复、自动重连、目录缓存重试、离线聊天目录及准确请求解析。
- 普通初始化不再启动CLI检查，也不让旧CLI位置阻断本机连接；旧服务和观察地址保留但不作为普通输入或连接条件。
- 检查连接只报告目录与传输的实际结果，不用一次握手声称提问／批准观察全部就绪。
- “测试已关联聊天”只复用已有监测快照，不另建连接或订阅；重新检查也不销毁并重建已有正常观察器。
- 撤出文件inProgress合成执行、错误转探测、同一旧记录超时后续期、跨未知轮次终态补报。文件只作发现线索、诊断及已确认同轮终态补齐。
- 发现窗口使用硬截止；mtime单变、投影落后或读取错误不会开启窗口，同一未确认轮次不因重连反复尝试。可信实时长轮次／等待保留，失去可信流后有固定宽限。
- 文件轮次与投影水位在同一只读事务中读取；偏移超过当前文件长度也按未追平处理，拒绝网络文件路径。
- 修复断线后先未知、再补到同轮完成时的漏收与显示覆盖；同绑定编辑保存保留当前确认记录，改绑和旧存档不能继承。

## 设置窗口

- 七个入口按日常偏好与平台连接分组，使用短名称、统一页头与用途说明、卡片留白和清楚的主次动作。
- 保留自动保存和固定手动保存反馈；所有原设置功能和选项仍可到达。
- 常用项直接显示，启动修复、存储位置、通知高级信息、Codex路径与兼容工具折叠。
- AI页突出检查结果、下一步及分项能力；本次目录／路径／保存失败优先显示，不被已连接通道掩盖。
- 移除普通界面的旧端口／服务地址、内部事件计数和未接入平台的无效配置表单，不删除旧保存值。

## 边界

这不是严格零副作用监测的完成版本。发现窗口仍可能推迟闲置起点；长轮次／等待继续使用本机实时订阅。未曾实时捕获的极短轮次可能保持待确认，不用旧文件记录猜测。原桌面完整问答／批准／恢复与系统级流量计量按验收中的未完成项报告。
