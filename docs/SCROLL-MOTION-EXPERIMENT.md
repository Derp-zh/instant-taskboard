# 画卷窗口动效实验

2026-10-14。原实验分支：`codex/scroll-window-motion`。用户已授权并入正式程序，已于0.8.2移植，现纳入0.9.0；下文的实验包和原分支说明作为来源记录。当前整合验证见[0.9.0验证](VERIFICATION-0.9.0.json)。

## 已确认效果

- 仅修改新建任务宿主、已建任务编辑、设置窗口的显示与隐藏动效。
- 中央向左右揭开，关闭向中央收拢；背景与文字一起裁剪，文字不被压扁。
- 中央为竖向细白线，带柔光；展开开始和收起最后短闪。
- 用户补充：完整播放时间为 **100毫秒**，包括白线闪烁；白线贯穿窗口全高，与上下边缘对齐。
- 白线阶段25毫秒，画卷阶段75毫秒。快速反向从当前位置继续，剩余播放时长按距离缩短。
- 原任务保存、草稿暂存、X放弃修改、球收起保留修改等规则仍适用。退出进程直接释放窗口，不等待动画。

## 如何体验

双击实验包的“启动画卷实验.cmd”。它使用包内独立的 `experimental-data`，关闭外部接入，不添加正式开机启动或快捷方式。

点击实验悬浮球展开列表，点击“进行中”等列表的虚线新建入口；保存一条实验任务后点击卡片体验编辑。设置可由球右键菜单打开。每个窗口右上角X可体验收起；也可以用球统一收起、重开。

灵感库的列内编辑没有独立窗口，因此不参与此实验。多个草稿切换继续在同一窗口内进行，不对每次输入或切换重播动效。

## 验证方式

最终自包含体验包：39项动效/兼容检查、77项原有窗口回归通过；核心87项规则检查通过。全高白线的端点距上下边缘不超过3个采样像素。证据与运行文件哈希见[验证记录](SCROLL-MOTION-VERIFICATION.json)。实际鼠标点击由用户试用确认，不将程序化控件调用冒充鼠标验收。

规则检查用新的 `--data-dir`。动效检查用 `--scroll-verify --data-dir <新的隔离目录> --no-integrations`，采样实际桌面的横向像素条与中央纵向像素条，检查白线、全高对齐、对称中间画面、反向、关闭残留及保存边界；不移动鼠标。

动画由Windows合成器播放。100毫秒是动画时间，首次布局与画面准备的耗时另外记录；可见帧数受显示器刷新率限制。采样不是帧率或其他设备验收证明。系统合成不支持时继续使用原暗色兼容背景与直接显示/隐藏。

## 构建

使用 `tools/Build-ScrollExperiment.ps1`。发布到新的实验目录，不覆盖含实验数据或正式数据的目录。必要时以 `-PackageCache` 指定本地缓存。
