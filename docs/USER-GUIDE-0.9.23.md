# 即时任务看板 0.9.23 使用说明

适用于 Windows 10 2004 或更新版本、Windows 11，64 位。运行包自带 .NET。

## 开始与升级

1. 下载 `instant-taskboard-0.9.23-win-x64.zip`，完整解压到新目录，运行“即时任务看板.exe”；保留目录内全部文件。
2. 升级前从旧版托盘菜单退出看板。程序与任务数据分开保存，升级不会主动迁移或清空数据。不需要退出 Codex。
3. 点击悬浮球展开六个独立列表；灵感库可以直接输入，其他列表的新建入口可填写完整任务。默认快捷键为 Ctrl+~。
4. 首次 AI 初始化提示可选“稍后配置”，不影响普通使用，后续不会每次启动反复提示。

## 阶段与列表

- 在新建或编辑窗口中，点击阶段名称右侧圆形 X 删除阶段。编辑内的删除需保存任务才正式提交；取消保留原任务。
- 至少保留一个阶段，也必须保留一个运行中的阶段。要删除唯一运行阶段，先将另一个阶段设为运行；禁止删除时显示提示气泡。
- 六个内置列表均可改名、隐藏和重新显示，不能删除。新增的自定义列表清空任务和非空草稿后可删除。
- 旧版本曾删除的“完善中、暂搁置、已完成”会恢复为隐藏，保留原名称；不会强制弹出窗口。
- 卡片可拖动排序/移列，搜索涵盖任务名称与阶段详情。完成仍由用户手动确认；归档可以恢复。

## 设置与提醒

- 设置保留主设置、窗口、监听、归档、数据与备份、AI平台接入、飞书接入七项导航。相关控件按用途分组，按钮可换行。
- 设置沿用即时生效与自动保存；右上“保存设置”可立即保存并显示结果。修改全局快捷键仍需点“应用快捷键”。
- 可调整窗口大小/透明度、球右边缘吸附、自启、提醒和通知提示音。监听默认关闭，通知声音与 Codex 移列是不同功能。
- 球从边缘弹出时，红点完全消失和数字出现由同一动画帧更新。0.9.22已在主屏150%缩放补验一次悬停，其他环境仍待验证。

## Codex 初始化与关联聊天

用户默认已经安装 Codex。设置 → AI平台接入 → 初始化AI平台配置，点击“一键初始化／重新检查”。程序先尝试连接，分别显示聊天搜索、实时连接和提问／批准观察；版本变了不会直接拒绝连接。旧服务地址及有效手动路径保留，商店升级的失效路径可自动刷新并备份。

在任务阶段搜索并选择已有聊天后，可点“测试已关联聊天”。它只读当前状态，说明哪些聊天可读、正在执行还是等待；不创建聊天、不发消息、不代答或批准，不改任务。未发生的提问／批准／恢复仍显示未验证。

若显示“Codex已连接，完整状态观察待开启”，基础连接已经可用；请在方便时保存工作并自行退出Codex，再从看板点“打开Codex并开启状态观察”，确认后打开。看板不会代你退出或重启。普通重开可能失去观察入口，重新检查会说明实际缺项。不需要脚本、环境变量或手填参数。

连接失败会提示具体下一步。找不到程序或原手动路径无效时，展开“手动选择与诊断（可选）”，分别选择桌面程序和CLI；二者不能混用。全部原配置选项保留在诊断中。

本机26.1016.8120.0的目录、原桌面身份与只读通道已实查通过；已增加其imn/nct状态观察适配，保留旧Hfn/Dot结构。未开放观察端点，故新版原桌面提问／批准／恢复尚未实机验收。内部结构不符时只提示该观察功能暂不支持，不把整个平台判为不兼容，不猜未知对象。

自动移列规则不变：真实执行进入进行中；问题、批准等待及整轮结束／失败／停止进入待操作；回答或批准后实际继续执行才恢复。多阶段等待优先，断线和未知不清除已确认等待。

## 本机数据与备份

默认任务目录 `%LOCALAPPDATA%/InstantTaskboard/data`，配置目录 `%LOCALAPPDATA%/InstantTaskboard/config`，均可在设置中调整。搬动程序目录不会自动带走系统数据；换电脑请同时备份实际任务与配置目录。设置中的“配置备份”只包含设置，不包含任务和草稿。

## 验证边界

本轮隔离检查与真实只读连接分开，详见[0.9.23验收](ACCEPTANCE-0.9.23.md)。没有移动鼠标、操作原聊天或重启Codex；新版原桌面提问／批准／实际恢复、多屏DPI和真实整轮失败／额度停止仍有未验收项。0.9.22的目标X与一次球悬停已有历史鼠标证据，本轮未重复操作。
