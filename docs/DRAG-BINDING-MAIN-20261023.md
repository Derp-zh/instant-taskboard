# 拖动绑定：本地主开发集成

2026-10-23。本轮按用户修订要求预设新版本0.9.24，将r2真实菜单链接路线接入普通主开发构建；本地开发中，未发布。已发布的0.9.23及其运行包保持原样。

完整解压运行包，直接打开“即时任务看板.exe”。保留现行任务路径、配置、自启与其他集成逻辑，不需要预览参数，不自动生成示例或打开六列。

在列表任务卡片的会话名称（或“未绑定”）处按住拖动，离开来源列后其他原可见列临时隐藏；放到Codex侧栏目标聊天或当前聊天正文后松开。看板通过该聊天的“复制→复制深度链接”取得准确编号，只改来源阶段并保存；侧栏目标不必先打开，不需要观察端口。

单击会话名称不改绑。Esc、右键或整组主动收起可取消。结束后只恢复原可见列，原先隐藏的列保持隐藏。原编辑器会话选择器、整卡拖动和阶段开关保留，灵感库例外及归档只读保持。

操作会短暂使用剪贴板，先完整缓存再恢复；无法完整缓存或目标不明确时保留原绑定。操作期间出现其他剪贴板内容时不覆盖。不会发送消息、回答、批准或重启Codex。

普通入口：`release/即时任务看板-0.9.24/即时任务看板.exe`。本轮普通包已复验三种原Codex真实目标、准确编号落盘和重开、Esc／右键取消、错误应用保护、其他阶段及原隐藏列不受影响；鼠标、前台与原剪贴板恢复均回读通过。其他隔离及原操作范围结果见[本版验收](ACCEPTANCE-0.9.24.md)。r2历史40项隔离/34项鼠标不是本包通过记录；多窗口、分屏、混合DPI、同名会话、远程host及自定义剪贴板格式保持专项边界。
