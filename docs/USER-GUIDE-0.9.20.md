# 即时任务看板使用说明（0.9.20）

## 下载与启动

从[GitHub 0.9.20 Release](https://github.com/Derp-zh/instant-taskboard/releases/tag/v0.9.20)下载Windows x64 ZIP及SHA256文件。先校验文件，完整解压，再运行`即时任务看板.exe`。无需单独安装.NET；请保留整个目录。更新前从托盘正常退出旧版。

## 管理任务

看板由灵感库、完善中、进行中、待操作、暂搁置、已完成六个独立窗口组成。通过暂存池快速记录，再把任务移动到合适的列表。一个任务可以拆成多个阶段；各阶段可独立关联会话。阶段名称显示在卡片正文上方：会话名称区域约3至5个中文字宽，长名称滚动，阶段气泡使用它左侧可用空间。

窗口可独立移动和调整大小。悬浮球与托盘提供常用入口。列表右键菜单可管理对应列表，卡片菜单用于任务操作。详细按键和设置请从应用菜单与托盘入口查看。

## 数据与备份

默认任务和配置分别保存在`%LOCALAPPDATA%/InstantTaskboard/data`和`%LOCALAPPDATA%/InstantTaskboard/config`。设置中的“数据与备份”可以查看或更改目录。备份不会自动合并已有数据；操作前请核对选择的目录。

升级时先正常退出旧版本，再完整解压新版到独立目录启动。保留用户数据目录，运行包本身不包含任务数据。

## 可选Codex观察

Codex观察默认关闭，需要兼容版本和PowerShell 7手动启动；它读取有限的结构化会话状态，不读聊天正文、不代答也不批准操作。观察功能不是通用AI接入。真实整轮失败及额度耗尽停止尚未完成实机验收。详见[公开观察说明](CODEX-PENDING-BRIDGE-PUBLIC.md)。

## 当前范围

飞书云端同步尚未接入。通知监听与Windows系统通知音替换仍有单独的实机验收边界。混合DPI多屏和真实鼠标操作未纳入0.9.20宽度修正版验收。问题反馈请到[GitHub Issues](https://github.com/Derp-zh/instant-taskboard/issues)。
