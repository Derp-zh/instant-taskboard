# 0.9.30 接入取舍与设置窗口验收

日期：2026-11-02。本地开发，不发布GitHub。用户授权按既有推荐做Codex接入优化取舍，并从用户操作角度重排设置窗口；版本指定0.9.30。

## 改动范围

保留0.9.21／23的初始化和分项检查、0.9.26的重连及目录重试、0.9.27的直接只读目录，以及既有准确请求／轮次解析、等待优先和保存合并。移除普通设置中的旧观察入口与无效表单，旧配置值保持。

0.9.28文件伪报执行和未确认轮次补投影退出正式状态判断。文件只发现候选，并安全补齐此前已经实时确认过的同轮终态。发现、收尾及失去可信实时流有固定截止；不能由同一条旧记录、写时间单变或反复重连续期。首次出现但从未实时确认的终态明确待确认，不能称F7完整捕获已修复。

设置消费者是SettingsSurface、各Settings分文件及初始化控制器；改动仅设置内部导航、分组、说明、折叠和能力显示。共享Ui／SurfaceWindow、背景、透明命中、六列操作、菜单位置、窗口层次、动画、拖动绑定和正式保存路径不改。原快捷键应用、自启、路径切换、归档及通知设置功能保留，测试不执行正式系统操作。
