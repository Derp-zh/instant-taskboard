# M11 设置与外部能力范围

现行规则，核对日期2026-11-02。

- M11-01：设置左栏按“偏好设置／平台连接”分组，可见名称为常规、窗口与列表、通知声音、归档、数据与备份、AI平台、飞书；七个旧导航key保持兼容。窗口区包含列表管理、独立尺寸入口、透明度和恢复默认；常规包含自启、快捷方式、灵感快捷录入、全局快捷键、球吸附开关。
- M11-02：Codex单独显示本次结果、下一步与目录／本机连接／逐聊天能力。未接入平台仅说明未接入与可用的分类功能，不展示无效连接表单；旧保存值保留。只有真实验证过的相应能力可显示成功，目录／传输与提问批准分开，本次目录、路径或保存失败不能被后台通道成功掩盖。
- M11-03：Codex现已专项授权并默认自动连接已有本机状态推送，按[C01](C01-Codex接入.md)的分层能力报告，无需专用启动或观察端口；“Codex待另行研究”不再作为当前全部状态。DSH只读探索已授权，实际接口/缺口及待选路线见[C02](C02-DSH接入探索.md)，尚未实施产品监听；dsh/workbuddy在产品中仍显示分类与未接入入口。
- M11-04：飞书连接配置及未来双向同步、本地离线副本方向保留；实际连接、目标表字段、阶段映射、冲突粒度、删除传播及频率仍待专项确定。配置导入成功不等于已拉取云端任务。手机改任务不自动启动电脑AI，远程执行不在已授权范围。
- M11-05：不默认新增自动猜测会话、抓AI正文、任务协作共享、附件、复杂富文本、阶段拖动排序或远程启动AI。参考旧程序思路不等于需求或验收。建议/未确认选项不能当已确定规则。
- M11-06：无AI初始化提示记录时首次显示“关联Codex聊天后，看板可以根据执行状态自动移列。”，提供“一键初始化/稍后配置”；显示及稍后决定持久化，正常再次启动不反复弹出，不妨碍普通看板。已有配置先检查沿用，不直接覆盖或清空。
- M11-07：AI平台内只需检查连接与测试已关联聊天。普通初始化检查本机安装和目录／传输，不启动CLI、不以CLI或旧观察地址作为前置条件，也不通过握手声称逐聊天提问批准已就绪。“测试已关联聊天”只复用观察器已有快照，不新建订阅、刷新、发消息或修改任务。路径失效才展开手动修复；CLI仅可选兼容诊断，旧端口／服务地址输入退出普通界面但原值不删。初始化不销毁已有正常观察器；连接结果以本次能力为准。
- M11-08：设置统一页头、用途说明、卡片边距和主次动作；常用项直接可见，启动修复、存储位置、通知高级信息和连接诊断折叠。保留已实现原功能、选项与事件，相关动作可并排且窄处换行，未接入的无效表单和重复技术说明可移除。保持即时生效与自动保存，顶栏固定手动保存及成功／失败反馈，不要求多一步才生效，不改共享窗口层次、背景、命中或其他操作范围。

验收：逐卡未配置/失败/停用/实际成功，首次提示/稍后/再次启动、设置重复初始化、自动发现与手选、旧配置、未运行/失效/不兼容均覆盖；设置入口不丢既有操作。配置、来源身份、实时能力及生命周期分别报告。飞书/其他AI实际接入需要用户专项确认，不因界面整理扩大授权。
