# M11 设置与外部能力范围

现行规则，核对日期2026-10-22。

- M11-01：设置左栏含主设置、窗口、监听、归档、数据与备份、AI平台接入、飞书接入；平台/优先级选项在编辑内管理。窗口区包含列表管理、独立尺寸入口、透明度和恢复默认；主设置包含自启、快捷方式、灵感快捷录入、全局快捷键、球吸附开关。
- M11-02：AI每平台一张卡，启用勾选展开配置。未配置、连接中、失败、停用及实际成功分开，只有真实验证成功才显示已连接/绿色；配置存在、目录可读、选中平台都不能冒充完整实时能力。
- M11-03：Codex现已专项授权并提供可选本机观察路线，按[C01](C01-Codex接入.md)的分层能力和默认关闭规则报告；“Codex待另行研究”不再作为当前全部状态。DSH只读探索已授权，实际接口/缺口及待选路线见[C02](C02-DSH接入探索.md)，尚未实施产品监听；dsh/workbuddy在产品中仍显示分类与未接入入口。
- M11-04：飞书连接配置及未来双向同步、本地离线副本方向保留；实际连接、目标表字段、阶段映射、冲突粒度、删除传播及频率仍待专项确定。配置导入成功不等于已拉取云端任务。手机改任务不自动启动电脑AI，远程执行不在已授权范围。
- M11-05：不默认新增自动猜测会话、抓AI正文、任务协作共享、附件、复杂富文本、阶段拖动排序或远程启动AI。参考旧程序思路不等于需求或验收。建议/未确认选项不能当已确定规则。
- M11-06：无AI初始化提示记录时首次显示“关联Codex聊天后，看板可以根据执行状态自动移列。”，提供“一键初始化/稍后配置”；显示及稍后决定持久化，正常再次启动不反复弹出，不妨碍普通看板。已有配置先检查沿用，不直接覆盖或清空。
- M11-07：AI平台接入内提供“初始化AI平台配置”，本轮仅Codex，含一键初始化/重新检查、分别手动选择桌面程序与CLI、可展开诊断及明确修复动作；进度/未找到/不兼容/需重开/配置完成分开。无绑定明确具体聊天未验证，技术协议不作为普通用户必填项。设置重进和看板重开保留路径，连接能力以本次检查为准，不复用旧成功。
- M11-08：设置页保留原导航、全部功能和选项，仅优化分组、留白、列表名称编辑与操作按钮布局。相关动作可并排且窄处换行；窗口页区分内置/自定义列表和透明度设置。保留即时生效与自动保存，增加明确手动保存及成功/失败反馈，不要求用户多一步才生效，不改变窗口层次或其他操作范围。

验收：逐卡未配置/失败/停用/实际成功，首次提示/稍后/再次启动、设置重复初始化、自动发现与手选、旧配置、未运行/失效/不兼容均覆盖；设置入口不丢既有操作。配置、来源身份、实时能力及生命周期分别报告。飞书/其他AI实际接入需要用户专项确认，不因界面整理扩大授权。

依据：R68至R73/R83、原范围第1/15节、U20/U32/U37/U54；通知见[N01](N01-通知监听.md)。
