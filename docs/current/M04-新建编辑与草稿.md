# M04 新建、编辑与共享草稿

现行规则，核对日期2026-10-21。以下动作表是提交行为的权威说明。

## 操作与提交

| 动作 | 新建草稿 | 已建任务编辑 | 设置 |
| --- | --- | --- | --- |
| 右上关闭 | X关闭整个草稿宿主，暂存全部非空草稿 | “取消保存”放弃未提交副本并关闭 | 关闭设置 |
| 右下保存 | 验证后提交一份正式任务并移除对应草稿 | 合并已改字段并落盘 | 按原设置操作生效 |
| 同一任务卡片/同一设置入口再次点击 | 新建入口不作为开关 | 关闭对应编辑，保留未提交副本，不正式提交 | 切换关闭 |
| 球/快捷键收起、真实点击其他应用 | 隐藏整组，保留输入 | 隐藏整组，保留副本 | 隐藏整组 |
| 本看板内、悬浮窗外单击 | 保持 | 保持 | 保持 |
| 列表空白/标题内符合系统阈值的左键双击 | 暂存并关闭最上层宿主 | 与保存按钮共用验证和落盘，成功才关闭；失败保持输入 | 隐藏最上层设置 |

- M04-01：表中任务卡片正常操作不算“外部双击”；内部点击、非左键或任务卡片操作打断外点序列。菜单、日历及所属原生对话框视为内部。使用实际按下时间及系统双击时间/位置范围，不用UI延迟投递时间。焦点改变及Alt+Tab本身不触发整组收起。
- M04-02：同一任务仅一个编辑窗口，已建编辑不参与新建堆叠。编辑开启动画达到2/5后允许再次点击原卡片关闭，此前忽略；不统一过滤物理双击第二次按下。退出保留未提交编辑，重启恢复现场，正式值仍为已提交值。
- M04-03：独立列表的新建每次建立新卡片并预选该列，同时恢复旧共享草稿且不覆盖旧内容/状态；新空卡片不持久化。宿主内部新建不预选/继承状态。未选状态可暂存，正式保存必须先选。
- M04-04：非空草稿保存全部字段，包括自定义列表、全部阶段、运行标记、平台、优先级、提醒和阶段会话，自动暂存可跨进程重启；空后台页在切换新任务时清除。重复正式保存不得创建重复任务，写入失败保留可重试内容。
- M04-05：新建共享一个真实宿主。前台完整编辑居中，旧草稿向右错开1/5，右端虚线＋新建入口无毛玻璃底板且文字居中；切换保留输入及编辑位置。顶部72DIP及编号区域只移动，不切换；下方后台露出部分整块只切换，后台按钮/输入均不操作。
- M04-06：草稿按创建时间连续编号1至N，删除/保存后重排，无历史占位；兼容旧创建时间。后台编号保持原始小圆形尺寸、白边和亮度，多位缩放，只显示编号。前台X为48×40；编辑“取消保存”与“保存任务”实际等宽等高。左下删除及右下保存高度40，保存文字深蓝黑#102033。
- M04-07：左下删除新建只删当前草稿；编辑删除正式任务并可撤销。X关闭新建整个宿主与删除当前草稿不同。最后草稿收起完成才清真实控件，快速重开取消旧清理，不能关闭中空白或误清新输入。
- M04-08：字段顺序为名称、详情、当前状态、平台、优先级、定时提醒；状态/平台/优先级同一行。默认高度550，旧高度不突破新默认上限；宽度和字号保持。首个编辑居中、后续右32/下32且限制工作区。新建/设置真正重开居中，重复调用仍打开的窗口不跳位，整组恢复保留位置和尺寸。
- M04-09：保存期间拦截重复输入、键盘/输入法和粘贴，不整体禁用控件造成变暗。保存失败可见，窗口与输入保留。输入圆角矩形内留白全可点击，轮廓外不触发。
- M04-10：暂存切换采用同宿主纯横向抽牌，原360ms路径整体1.35倍，约266.67ms，无纵向移动；抽出结束、返回前新卡升到前层再盖回。前2/3点击忽略，最后1/3最多登记一次后续切换，后点不覆盖；准备阶段不登记，以原始按下时间判断。结束/中断恢复边界、图层和输入，不重播普通画卷。只补草稿上下圆角露出缺口，不叠整条纵向暗底。
- M04-11：虚线新建轮廓左侧与末卡圆角起点对齐，既有点击起点保持，右侧多余范围裁掉。顶部移动与切换范围不得因外观改变。新建/编辑背景及开合见[共享表面](SURFACE-背景动画与输入.md)。

## 验收

分别新建/编辑验证全部动作表、未选状态、详情独填、三份非空草稿、全字段重启恢复、同卡开关、快速重开、保存失败、编辑与后台交错。保存不能仅用内存值验收，需回读隔离磁盘数据。抽牌验证前2/3和最后1/3不同输入时机。
