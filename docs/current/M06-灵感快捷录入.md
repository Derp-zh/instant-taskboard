# M06 灵感库快捷录入

现行规则，核对日期2026-10-21。

- M06-01：主设置“灵感快捷卡片”默认开启。开启时末尾新建在原位置列内录入，不开独立新建窗口；关闭时打开预选灵感库的完整新建。切换开关先保留当前输入，选择跨重启保存。
- M06-02：快捷卡片与正式卡片共享圆角、边框、内边距、标题青色和详情白色布局，无大输入框、独立说明或整行保存按钮。录入期间只保留该位置一张卡片，非空自动保存时不另插重复正式卡片。
- M06-03：详情框有独立圆角边框，至少两行；内容增长沿用滚动上限，有两行以上不补空行。✓为详情框内右下小圆胶囊，文字避开它；点击✓或卡片外任意位置保存最后字符并结束，卡片内换焦点不结束；收起/退出保留输入。名称或详情非空才保存，空内容及仅阶段名不建任务；允许详情独填。
- M06-04：标题最右圆按钮转完整窗口，不丢最后字符或状态，不重复任务：尚未自动保存则转暂存新建，已保存则编辑同一任务。已有正式灵感卡片仍可按正常卡片规则打开编辑。
- M06-05：多阶段灵感任务按[M05](M05-阶段与卡片.md)显示运行阶段，跨列保留全部阶段，不删除隐藏阶段；快捷新建仍从阶段0开始。灵感库列表不显示会话名称及运行/未运行图标，完整编辑器可配置。

验收：开关、非空自动保存、详情独填、离开/✓/球收起/退出最后字符、两个转完整窗口分支、无重复卡片、跨列所有阶段保留、快捷入口整块命中。

依据：R42至R45、D04/D05、U06/U56/U57/U107至U109/U113/U132。
