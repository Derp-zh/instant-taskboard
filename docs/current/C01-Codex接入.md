# C01 Codex接入、聚合与恢复

现行规则，核对日期2026-10-22。规则与“是否已实机验收”分开，结果见[当前状态](STATUS.md)。

- C01-01：优先原Codex桌面，兼容终端，手动选择准确已有会话，按阶段保存编号/名称和绑定代次。分类选中不代表连接。只读产品不创建/迁移/接管聊天、不发消息、不代答/批准、不改全局权限。不擅自关闭、重启或打断Codex，无退出后持续监测需求；初始化需观察启动参数时，只在用户自行退出后，经界面主动确认打开，正在使用则保留待完成。
- C01-02：目录、传输、来源身份、逐会话实时能力、原桌面生命周期及实际卡片/持久化分别报告。独立历史服务、未加载、非本机host、目录成功或夹具不算实时。部分诊断退出3/完整passed=false不能改写为全通过。
- C01-03：仅内置进行中/待操作参与自动双向流转；其他四列、自定义列及未运行阶段不自动移动。多个运行阶段有等待回答/批准、结果待检查、准确失败/中断时优先待操作，另一阶段运行不能盖过。正常结束待检查，不自动完成。
- C01-04：带选项或自由输入的提问、同步Plan及人工批准都按准确结构化请求ID维护；完整请求集合及批准子集，空active、单resolved或同数量ID更换不能丢等待。同数量ID更换也必须保存。只回答、点击批准或请求消失不等于实际恢复；要联合准确同轮次实际执行和请求完整性判断，首帧等待原子处理。
- C01-05：已确认待处理保护跨断线/重连保持，不能因Unknown、另一阶段运行或旧终态清除。可信实际恢复并整卡回进行中时清时间红点；整卡仍待操作不清。新绑定、改绑、解绑重绑和归档恢复重置旧信任/保护；保留必要会话编号，拒绝旧绑定/epoch/序号及重复终态。主动编辑保存清任务红点保持，旧副本不覆盖后台。
- C01-06：当前准确轮次failed/interrupted、用户停止、整轮执行报错、明确额度用尽导致停止进入待操作，参与多阶段及重连保护。普通命令非零、临时错误重试、余额快照、断网/退出/Unknown本身不算整轮失败或额度停止。非重试error需准确当前轮次和明确额度枚举，不猜错误正文。
- C01-07：正常终态补查仅当前绑定已观察准确轮次；快停止补查需同epoch已有轮次及合法严格递增最新Unix秒水位，明确最新失败/中断且不同轮次才能直接待处理，不伪造运行/清点。首次历史、同秒、无基线、重连依据未重建均不猜。内部probe不允许外部Receive调用。
- C01-08：可选本机结构化请求观察默认关闭；一键初始化是明确启用入口，保存本机观察地址，不要求用户填环境变量或运行脚本，旧显式环境入口仍兼容。核对原管道身份、同用户/SID/Windows Session、监听PID、唯一无query/fragment主页面及两模块哈希。无包身份仅动态系统登记的原安装最终路径+精确兼容exe哈希，不写死带版本号的安装目录。未知升级或不匹配时不可用，不能自动猜新对象。
- C01-09：固定读取原请求索引，仅留编号/类型/归属/轮次/完整性及执行布尔值，不猜UI、不保存提问/答案/正文/令牌；不暂停、断点、遍历模块作用域、改安装/ASAR/fuse/CLI。初读允许约20秒，复用健康连接；线程暂不可读不重复GC。不可用时保留已确认保护。
- C01-10：普通重开Codex未带观察参数可能失去新增请求能力，应明确报告；初始化提供“打开Codex并完成配置”，检查仍在运行则拒绝启动，不代替用户退出。端口冲突、未知版本、失效路径各给可操作下一步，未经确认不得执行桌面启动。具体兼容版本、端点与哈希见[观察模式说明](../CODEX-PENDING-BRIDGE-PUBLIC.md)，不用旧PID直接操作。
- C01-11：初始化分别报告安装发现、可用CLI、聊天目录、原桌面身份、准确模块及请求观察源和具体聊天能力。只有目录与完整观察源本次检查均通过才显示“配置完成·连接已准备好”；无绑定时具体聊天未验证。有绑定仅报告实际可读及请求观察情况，不将未发生的提问/批准/恢复生命周期写成通过。初始化不自动选择、创建或接管聊天，不发送验证消息。
- C01-12：现有有效手动桌面/CLI路径和服务地址优先沿用；失效原值保留供修复，未知版本停止内部读取。桌面和CLI分别发现，优先Windows商店登记及manifest实际位置，不将同名启动辅助程序当CLI。仅用户明确“改用原Codex桌面连接”才备份并切换原服务配置。

## 验收

隔离看板+获准原桌面测试聊天，分别证明原选项/输入同卡等待与回答、Plan、批准等待与执行、停止、失败、额度停止；卡片/实际存储/红点独立回读。多阶段等待优先、跨重连、旧终态不重放、解绑重绑/归档恢复、编辑合并必回归。不要主动耗尽额度，不把新发消息替代回答原卡片，不合并模拟断言与真实场景数量。

当前已有证据与缺口见[状态表](STATUS.md)，本页不把旧版“异步提问未支持”继续作为当前观察模式能力结论，也不把四项真实覆盖改成六项全部验收。

初始化验收另见[初始化公开验收](../ACCEPTANCE-0.9.22-PUBLIC.md)：首次/稍后/重开、设置重检、自动及手动路径、原配置、未运行/不兼容、目录与观察源区分、选择器及实际保存；夹具和原桌面生命周期分别报告。

依据：R71/R72/R85至R87、D12最新有效部分、U32/U105/U111/U170至U175/U183至U193及PRD40用户补充。旧“失败/中断不移列”“AI恢复不清点”均已失效。
