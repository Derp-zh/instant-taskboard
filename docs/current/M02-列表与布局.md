# M02 独立列表与布局

现行规则，核对日期2026-10-22。

## 有效规则

- M02-01：默认六个独立窗口，从左到右为灵感库、完善中、进行中、待操作、暂搁置、已完成，同时展开/收起，没有单列关闭按钮。内部角色与显示名称分开。
- M02-02：默认最大范围约屏宽7/8、工作区居中、避开任务栏；列间距24DIP，窄屏适当缩小间距、缩窄列但保持并排。默认宽高采用已确认的0.87比例及既定高度，标题区42DIP。已有用户手动布局优先，不因更新强制重排。
- M02-03：各列独立移动和拉伸，持久保存，不挤压邻列。顶部一行可左键拖动、无专用图形且指针不变；标题、菜单等实际控件不得被拖动区挡住。
- M02-04：单列菜单有“调整本窗口大小/结束调整”切换项，Esc及四边拖完同步结束；另有“本窗口恢复到默认”，只恢复该列在当前整组缩放基准下的尺寸和槽位。设置可统一显示/隐藏各列右下角缩放入口。
- M02-05：灵感库左下22×22DIP图案整块按住可同比缩放六列位置和大小，最大范围始终在工作区中央；松开结束并保存，不影响球、新建、编辑及设置。球/托盘/设置的“恢复窗口默认”恢复六列和球原始默认大小位置并重置组缩放，不改任务。
- M02-06：设置“窗口”管理列表数量、名称、新增、隐藏和删除。隐藏不计显示数量。六个内置列表均可改名/隐藏、不可删除；仅自定义列表可删除，含正式任务或非空草稿时仍不可删。旧配置中曾删除的完善中、暂搁置、已完成恢复为隐藏，保留原名称/身份，不强制显示。删除空自定义列表后撤销任务操作必须恢复原身份，配置导入保护任务列表引用。
- M02-07：列表根透明空白也属于完整交互面，保留空白右键、标题拖动、整组/单列缩放、卡片、新建、滚动条操作。虚线新建入口整块轮廓内部可点，不限于文字；入口在滚动内容末尾，不固定在底部。

## 验收与边界

分别验证单列/整组缩放和两种恢复基准、六个内置列禁删及隐藏/改名身份、旧删三列恢复隐藏、自定义非空删除拒绝、撤销恢复引用、空白右键和虚线内部角部。混合DPI、热插拔仍未全面验收。开合、背景及滚动见[共享表面](SURFACE-背景动画与输入.md)。
