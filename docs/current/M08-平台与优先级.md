# M08 平台、优先级及颜色

现行规则，核对日期2026-10-21。

- M08-01：界面统一称“平台”，默认codex、dsh、workbuddy，多选；优先级默认紧急、重要不紧急、不重要不紧急，单选。两者都可不选，可新增、改名、改色、删除。
- M08-02：选项管理在新建/编辑窗口内，不放设置分区；选项右侧色彩按钮只改颜色，不改变选中状态。颜色保存在选项定义，所有引用任务胶囊同步，深色背景清晰可读。
- M08-03：删除被引用选项后清空全部任务/草稿的该选择，不强制替代项。选择框首次点击展开，再点同一框收起，外点关闭，多选保持。
- M08-04：平台选项是分类或关联意图，不等于实际连接；新增选项不自动获得监听。内部字段可兼容旧AiIds命名，不因显示更名丢选择、颜色或关联。

验收：多选/单选/空选、色彩按钮不误选、同框开关、删除已引用选项、同步改色及重启回读。接入能力见[C01](C01-Codex接入.md)和[M11](M11-设置与外部边界.md)。

依据：R50至R54/R54a、D08、U20/U29/U66。
