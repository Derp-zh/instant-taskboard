# M10 时间提醒与待操作预览

现行规则，核对日期2026-10-21。

- M10-01：提醒支持每天、每周、一次性；仅22DIP勾选圆切换设置展开，文字和整行空白不触发，键盘操作保留。草稿只存配置，正式保存后生效；收起、球隐藏继续，退出停止。
- M10-02：到期进入待操作、记录到期原因并一次系统轻提示。同一次到期不重复，休眠/重启错过多个周期只补一次并推进；已完成停止提醒。时间和AI待处理原因分开保存，不相互覆盖。
- M10-03：AI可信实际恢复且整卡从待操作回进行中，同时清时间红点。只回答/批准、单请求消失、idle/未知、重复运行快照、另一阶段仍待处理都不算整卡恢复，不清点。主动编辑保存清该任务红点保持；其他既有主动操作不由本次整理扩展或缩小，源码入口见[共享链路](../architecture/SHARED-CODE.md)。清点不取消后续周期。
- M10-04：面板收起悬停球，上方预览只显示待操作正式任务的名称、阶段详情、平台、优先级，不显示旧“当前/前一/后两项”的相邻阶段摘要；宽198DIP，换行可滚动，无任务空状态。当前源码按BoardEngine.CardStages取得运行阶段详情。球、预览及两者通道共同保持悬停，离开完整区域后延迟收起，不永久驻留。
- M10-05：预览点击展开并定位任务，展开后隐藏预览，菜单/预览使用期间不边缘隐藏。具体悬停延迟保留既有实现；基础文档400ms为建议值，不在此升级为确认。

验收：每天/每周/一次、草稿排除、收起到期、错过多个周期、已完成停提醒、红点与多阶段/重连/编辑交错、球到预览通道和点击定位。红点需实测整卡与保存结果，不能只验证单阶段事件。

依据：R60至R67/R85至R87、D10/D11/D12最新有效部分、U07/U35/U78/U173/U174/U178/U186。
