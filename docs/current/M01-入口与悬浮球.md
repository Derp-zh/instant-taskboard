# M01 入口、悬浮球与托盘

现行规则，核对日期2026-10-22。只描述当前有效要求；实现与未验收项见[当前状态](STATUS.md)。

## 有效规则

- M01-01：产品名“即时任务看板”。球左键及全局快捷键切换整组展开/收起，后台进程继续运行。收起隐藏列表、编辑、草稿、设置、搜索和辅助窗口，保留输入、位置、可见窗口及层次，恢复时不重开已主动关闭的窗口。球始终可操作且位于本程序窗口上方。
- M01-02：球左键不移动；右键短按松开弹菜单，右键长按拖动，拖后松开不弹菜单。自由球可自由移动；吸附球仅上下拖动。
- M01-03：球与托盘右键共用同一菜单、外观、子菜单和启用状态，第一项原显隐开关，第二项设置，其余包含展开/收起、恢复窗口默认、撤销/恢复、AI状态及退出。隐藏球后可从托盘恢复。只有退出结束进程；退出前保存，失败必须可见。
- M01-04：窗口不出现在任务栏和Alt+Tab，托盘保留。不以此承诺进程不可被系统识别。球及向左展开的设置/搜索组件位于工作区内并避开任务栏。
- M01-05：“悬浮球吸附到桌面边缘并自动隐藏”新配置/缺字段默认开启，已保存false保持。当前只实现右侧吸附：左半圆加右侧贴屏矩形，绘制、原生命中和内部按钮范围一致，左上透明角不扩大。左侧吸附及左右切换留后续。
- M01-06：开启吸附时，面板收起且鼠标离开2秒后隐藏，露出球宽1/4；展开、拖动、菜单或预览使用期间不隐藏。双向边缘位移动画100ms；移入露出区恢复完整球，不自动展开面板。关闭开关立即恢复自由圆球；保存位置不写边缘外坐标。
- M01-07：球数字只统计待操作内置身份的正式任务，排除草稿、自定义列表及其他身份；改名/隐藏不改统计，启动首显前刷新。零项隐藏，数字完整位于球内，多位缩小。边缘隐藏时用小红点替代数量气泡；红点总上移10DIP且与数量气泡边框同色，弹出开始渐隐。数字保留预布局，在红点完全消失的同一动画帧开始显示，不延后一帧、不重叠闪现；保持原100ms边缘位移动画及操作范围。后台提醒与监听不停。
- M01-08：吸附只改变球，不把菜单贴屏；右侧球菜单在球旁向左展开，保留8DIP间距；自由球原弹出位置保持。
- M01-09：主设置提供全局快捷键启用、录入、应用、恢复默认。默认Ctrl+~、无需Shift，按物理按键注册，不依赖输入法字符；按住不连发。失败/冲突提示且原快捷键可用，程序需保持运行。

## 验收与影响

分别操作自由球及吸附球的左右键、矩形角部、拖动、菜单；测试2秒隐藏、1/4露出、移入恢复、计数首显、后台更新、快捷键、整组恢复与托盘找回。鼠标测试先协调，使用隔离数据。窗口开合规则见[共享表面](SURFACE-背景动画与输入.md)，启动规则见[M12](M12-数据启动与交付.md)。
