# M05 阶段与卡片呈现

现行规则，核对日期2026-10-22；会话宽度采用0.9.20宽度修正版。

## 阶段与可见内容

- M05-01：默认阶段0，新阶段递增编号，编号与可编辑名称独立，改名不影响后续编号。可独立改名称/详情；“＋新阶段”在左侧。阶段名胶囊位于详情输入框内左上角，右邻增加圆形X删除该阶段；新建和编辑均提供，编辑保存后提交，取消不删除正式阶段。只剩一个阶段禁止删除；唯一运行阶段也沿用至少一个运行中的保护，使用M05-04同一气泡模块。删除不重排剩余阶段编号，不影响其输入和会话。不自行新增排序、富文本或附件。
- M05-02：每阶段独立“运行中/未运行”，可多阶段同时运行且至少一个运行。新任务阶段0运行，新阶段未运行；旧任务原当前阶段迁为运行、其他未运行。旧唯一当前阶段不控制新显示/汇总。切换仅改变看板标记，不向Codex发启动/暂停。
- M05-03：编辑器中切换保存后提交；列表切换立即生效并可撤销。阶段/详情提交不覆盖后台最新会话状态与其他入口新改的运行标记；合并、旧文件、撤销也保证至少一个运行阶段。
- M05-04：最后运行阶段不可关闭，不新增撤销记录、不联动开关编辑；只显示一个“至少保留一个运行中的阶段”气泡，当前屏幕工作区水平居中、62%高度、1.2秒消失，无额外系统淡出。未连接控件安静跳过，不弹通用错误窗口、不跟随锚点漂移。
- M05-05：多阶段任务卡片展示全部运行阶段，不限制四项、不展示相邻暂停阶段；各列表适用，包括灵感库的多阶段任务。所有阶段数据保持。单阶段列表卡片不显示阶段名及状态图标，详情/会话名按既有例外显示。灵感库会话及状态图标例外见[M06](M06-灵感快捷录入.md)。不得用隐藏阶段详情生成空名称任务的可见标题。
- M05-06：列表暂停某阶段后立即生效，本次显示暂留整块并变暗，重开运行立即变亮；阶段切换本身不整理暂留。之后任何任务的新建、打开/关闭编辑、保存、拖动、删除、归档/取消、撤销/恢复等明确人为操作统一整理全部任务；下次球/快捷键展开也整理。输入暂存、后台消息、自动流转不整理。缓存不持久化，重启按真实标记显示。
- M05-07：整理暂留阶段约180ms向上裁切收起，无窗口泛光白条；删除/归档整卡同样收起后移出。自动归档可收起对应整卡，不整理其他任务。未显示卡片直接刷新，不为动画滚动列表。
- M05-08：运行图标为两个静态竖矩形暂停符号，未运行为三角；新建/编辑内三角单独降低亮度。列表只显示可点击图标，编辑器图标加文字，归档预览只读；图标点击不触发任务编辑开关。

## 外观与名称行

- M05-09：任务标题加粗青色并带青色细竖条，正文白色。卡片内部纵向留白为原3/5（上下11→6.6、文字4→2.4），横向间距、卡片间距保持；阶段名12、阶段详情14，已移除的相邻阶段摘要不继续作为字号分支。底部仅平台和优先级胶囊，不重复摘要。阶段分隔线灰色，标题与阶段间为青色；共用一物理像素、同宽对齐，线本身不增布局高度。青线到首气泡留白与气泡到其下正文实际字形间距对齐。
- M05-10：名称行从右至左预算状态图标、会话名称、左侧阶段气泡。会话用实际继承字体3至5个“中”字宽，不按编码字节或大写M计宽；不足3字宽保留3字，超过5字滚动，短文本靠右。未绑定显示“未绑定”，灵感库隐藏会话名例外不变。
- M05-11：阶段气泡短名自然宽、左对齐，没有字符最小宽度；上限是扣除右侧图标/会话及原间距后的全部余宽。极窄时文字、边框和内边距一起裁切，不侵入右侧控件。列宽变化时同一卡片同步重算，右侧保持右锚。
- M05-12：溢出文字首停0.5秒，24DIP/秒单向慢滚，末停0.3秒，复位循环；无溢出不滚。球/快捷键展开从头，收起冻结，隐藏停止计时，滚动偏移不持久化。不显示冗余Codex状态行，关联数据仍保留；不可见的执行状态变化不重建卡片。

## 验收

阶段删除覆盖新建/编辑、仅剩一阶段、唯一运行阶段、阶段0删除后的有效指针和实际落盘、取消保存、撤销恢复、剩余阶段输入/会话及晚到后台等待；X在阶段名右邻，复用原固定位置气泡。离屏事件与物理鼠标分别报告。

覆盖至少一个运行、多运行、暂停暂留/全局整理、后台不整理、单阶段/灵感例外、归档只读、同一卡片窄宽变化、3/4/5/6中文及英文混合会话名、短/长阶段名和双文本滚动。分别检查实际保存的阶段、图标操作和任务卡片操作，不能只测提交前副本或重复认可同一错误宽度。
