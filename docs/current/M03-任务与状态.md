# M03 任务数据与状态

现行规则，核对日期2026-10-21。

- M03-01：区分草稿/已建任务、所在列表、AI执行状态。“已建”不等于位于进行中；阶段不等于列表。默认六列角色见[M02](M02-列表与布局.md)。
- M03-02：任务、阶段及列表身份稳定，改名、布局变化、跨列或未来同步不改变编号。保存顺序、字段选项引用、阶段运行标记及阶段会话绑定。
- M03-03：草稿不出现在正式列表、正式搜索、待操作预览和提醒中。名称或任一阶段详情含非空文字才有内容；仅阶段名、字段选择、新增空阶段不算。正式任务可只填详情，名称空时以允许展示的详情首行生成标题，不强制补名称。
- M03-04：任务当前状态与实际所在列表一致，自定义列表保持独立身份。跨列提交顺序，取消不改变；归档移出活动列表，普通删除不产生归档。
- M03-05：后台Codex只能驱动内置进行中/待操作，其他四类及自定义列保持人工归类；AI正常结束、失败、停止都不自动设为已完成。确切事件和提醒规则分别见[Codex](C01-Codex接入.md)及[M10](M10-提醒与预览.md)。
- M03-06：正式任务编辑只合并用户修改的字段；未修改的后台状态、提醒发生记录和阶段运行标记不能被旧编辑副本覆盖。具体提交边界见[M04](M04-新建编辑与草稿.md)。
- M03-07：旧数据读取需保持身份、阶段与关联，先备份；`preserved-data`不自动导入或删除。旧唯一当前阶段只用于迁移兼容，不重新作为新规则控制显示或流转。

验收：空内容、详情独填、草稿排除、跨列/自定义列、旧数据隔离读取、编辑与后台交错合并、重启回读。迁移正式数据需用户明确授权。

依据：R19至R22/R47/R72/R76/R80、D04/D05/D12、U37/U70/U103/U111/U114/U174/U192。
