# N01 Windows通知与逐应用声音

现行规则，核对日期2026-10-21。

- N01-01：设置监听区按应用配置声音、试听和开关，另有总开关，支持WAV、MP3、M4A等；收起面板继续监听，旧配置默认关闭，不因程序整合开启或覆盖已选音频。
- N01-02：使用用户指定Alarm04.wav为内置默认音，新增应用/旧空路径用它，可恢复默认。配置保存资源标识，不依赖机器绝对路径，移动/导入后仍可使用。
- N01-03：只有准确识别发送方且可播放替代音时才关闭该发送方Windows通知音，保留横幅及应用自身声音，其他应用不变。不以系统全局静音、应用静音或删除横幅替代。
- N01-04：关闭/删除规则或正常退出尝试恢复原音，保存原值供异常退出后重启恢复；来源或音频不可用时不关闭原音。注册表方式存在Windows兼容边界，不承诺所有版本立即生效。
- N01-05：通知音不是Codex准确会话/轮次状态来源，不能用它自动猜测任务流转。当前隔离声音和解码有证据，真实外部应用通知捕获与原音消除仍待专项验收。

验收：实际解码播放、默认资源、逐应用隔离、错误音频不关原音、关闭/删除/退出恢复与异常重启。真实通知替换测试另行协调；普通控件检查不等于实机通知成功。

依据：U38至U44；详细兼容研究仅在需要时查[监听说明](../NOTIFICATION-LISTENING.md)。
