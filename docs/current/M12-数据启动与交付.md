# M12 数据、启动、配置及交付

现行规则，核对日期2026-10-21。

- M12-01：程序文件夹便携，默认持久任务为`%LOCALAPPDATA%/InstantTaskboard/data`、配置为同根`config`，均可编辑。更新程序目录不改变保存路径；程序搬走不等于系统数据自动随包搬走，启动/快捷方式/Codex环境/显示器也不会自动迁移。固定小型路径入口记录自选路径，任务不存注册表。
- M12-02：自动写入串行、临时文件刷盘、备份/原子替换；任务、全部非空草稿/未提交编辑、阶段、选项、提醒、布局、设置可恢复。损坏检查完整字段，保留原件，优先有效备份/恢复副本；已有数据与备份缺失不得静默建立空数据覆盖。失败信息必须可见。
- M12-03：切换任务数据目录前保存未提交内容；空目录复制当前数据，已有有效数据经界面确认才打开，不自动合并、不删原目录；同目录互斥。首次发现旧便携数据时复制迁移保留原件，正被使用拒绝，已有系统数据不覆盖/混合。正式迁移及`preserved-data`导入不由测试自动进行。
- M12-04：配置导出仅设置、布局、选项定义、路径记录和连接配置，不含任务/详情/草稿/提醒正文。导入不覆盖任务，保护列表/选项引用；无效外机路径保留当前并提示。旧含任务备份不可当配置包导入。任务文件的恢复配置副本与对外配置包分开。
- M12-05：每台电脑首次创建桌面快捷方式、默认自启，保留用户关闭自启的选择；设置可手动修复。统一入口登记实际路径、版本、构建时间：最高存在版本优先，同版较新构建优先，旧版不降级。普通启动及启用自启更新入口，旧启动可转交已登记新版。不扫描全部快捷方式；登录实测与注册回读分开。
- M12-06：正式提交只合并用户改动字段，不覆盖后台新提醒/执行/运行标记；后台保存异步合并，单项变化增量更新，避免输入重建六列或同步写大文件。事件监听正确解除/不重复，隐藏停止无用高频更新。
- M12-07：性能目标为冷启≤2秒、常见响应≤0.2秒、300任务×4阶段/10草稿空闲平均CPU<1%、持续编辑100次无监听持续增长；属于验收目标，不写成所有设备保证。窗口真实裁切已接受繁忙掉帧，不能擅自恢复截图交接追求120帧。
- M12-08：普通修改不自动上传。用户明确要求更新GitHub时，同步源码/文档及对应Release，完整便携ZIP和SHA256，核对远端及下载完整性。独立本地构建不覆盖正在使用的运行包，测试不修改正式自启。
- M12-09：AI初始化的首次提示决定、桌面/CLI路径和本机连接配置纳入现有原子配置保存/备份；失败可见，未保存不得显示初始化完成。重开后恢复配置并重新检查实时能力，不把历史成功当当前连接。保持任务/编辑合并与配置导入边界，不引入任务或聊天正文到配置。

验收：始终隔离`--data-dir`，断网保存/重启恢复、写入失败、损坏备份、路径空目录/已有有效数据/互斥、配置不含业务数据、跨窗口合并、启动登记防降级、发布下载。桌面鼠标测试先协调，不关闭用户进程或重启Codex。

依据：R74至R84、D09、U20/U26/U34/U47/U48/U52/U54/U101/U164/U176/U188/U194/U198。
