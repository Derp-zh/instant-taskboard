# M09 搜索与阶段会话选择

现行规则，核对日期2026-10-21；任务搜索和会话目录搜索是不同功能。

- M09-01：展开球时左侧依次为设置和搜索，100ms向左展开，箭头光标、输入字符与光标实际可见，不显示空白装饰胶囊。搜索正式任务名称及全部阶段详情，不搜索草稿/平台/优先级。结果默认向上、空间不足调整高度/方向，超多滚动。
- M09-02：点击任务结果隐藏结果列表、定位正确列表及卡片并红闪两次，然后恢复原样，不改字段颜色。输入保留，X清输入及结果，面板收起也不自动清输入。搜索不替代六列数据。
- M09-03：编辑器阶段关联气泡宽度为左侧状态按钮的1.6倍，显示会话名称，缺名显示未命名会话；下方按名称包含匹配、忽略大小写，编号不参与搜索。结果及必要提示提供名称和编号，分页目录短期共享缓存，不新建聊天或发送消息。只有选择结果才改绑定，输入搜索不改；可明确解除，保存名称及编号后正式生效。
- M09-04：搜索框点击展开下拉，松开鼠标保持；最右无气泡上下箭头可重复展开/收起，焦点变化不自行折叠。阶段卡片内搜索框外只关下拉；只有点击阶段卡片外才关整个关联区。选定会话立即收起关联区，下次打开空输入预显示已绑定名称。无常规说明行，空目录/失败保留反馈。
- M09-05：会话绑定属于具体阶段，旧任务级关联迁到原当前阶段，保留必要历史与代次；改绑/解绑重置实时保护并拒绝过时事件。会话目录可读不等于实时监听可用。列表名称布局见[M05](M05-阶段与卡片.md)。

基础PRD对任务搜索“忽略大小写”和悬浮预览400ms提出过建议，未将建议升级为新确认要求；本轮整理不改变现有匹配和延迟实现。

验收：真实字符/光标、隐藏阶段搜索、结果定位和红闪、清空/保留、向上空间、目录分页、搜索不改绑、选择后保存、卡片内外收起边界、失败反馈。外部目录操作与控件测试分层记录。

依据：R55至R59、U23/U28/U105/U120/U128/U131/U154/U155。
