# M07 卡片操作、撤销与归档

现行规则，核对日期2026-10-21。

- M07-01：卡片左键正常点击打开/切换对应编辑，内部按钮优先执行自身动作并打断外点序列。按下移动超过拖动阈值才拖动，不误开编辑；列表空白/标题双击行为见[M04](M04-新建编辑与草稿.md)。
- M07-02：拖动卡片图像跟随鼠标，目标位置虚线卡片占位，其他卡片呈现落下后的布局。只在开始生成一次图像、目标改变才调预览，松手提交一次排序/跨列；取消、非法落点保持。跨窗缝不误收起，窗体拖动、卡片拖动、文字选择分开。跟随明显卡顿需讨论取舍，不能自行删行为。
- M07-03：撤销/恢复为本次运行最近20步，覆盖删除、跨列移动、排序、已提交字段、列表阶段运行标记。输入不计步，无20秒限制；新正式操作清恢复分支。历史重放不得覆盖后台AI/提醒。归档/取消归档走专用入口，不借撤销重放淘汰数据。
- M07-04：已完成和暂搁置内置角色卡片右键可归档。归档完整已提交任务及阶段字段，从活动列表移除、停止后台处理，清对应撤销引用。普通删除不产生归档。
- M07-05：设置归档页首次构建最近20条预览，可加载全部；重入或真正重开设置恢复20条，预览数量不等于存储上限。取消归档恢复相同任务身份、完整阶段及原列表，已删原列表恢复相应角色。保留Codex编号，但重置代次、实时信任及等待保护。
- M07-06：已完成超过天数自动归档默认开启，默认5天，可填1至36500整数；从进入已完成计时，严格超过整天数才归档。编辑不重置、离开清除、再进入重计；缺计时仅初始化当前时间。运行约每分钟和启动检查，有未提交编辑副本先保留；关闭则不自动归档。
- M07-07：“只保留最近40条归档”默认关闭，关闭不按数量淘汰；开启超40时先说明实际永久删除数量，经界面确认才开启并删除，以后维护保持40条。不可撤销找回已淘汰归档。
- M07-08：人为删除/归档可等待180ms整卡上拉收起再移出。后台AI/提醒的自动移列则先提交真实状态和保存通知，再播放移出上拉/移入下拉，不能等动画完成才保存；隐藏仅更新，快速反向无重复/零高残留。

验收：点击与拖动区分、跨列/排序/取消重启回读、20步撤销/恢复与后台交错、归档/取消、默认5天严格边界/编辑不重计、未提交副本保护、20条预览/不限存储/40条确认、动画取消。

依据：R46至R49、D06、U31/U50/U51/U53/U93/U118/U119/U122至U124/U178。
