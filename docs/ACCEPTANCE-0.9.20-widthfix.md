# 0.9.20宽度修正版验收摘要

版本以0.9.20发布，包目录和文件名增加`widthfix`，便于与首次0.9.20本地包区分。会话名称区域按实际字体限定为约3至5个中文字符宽；超过上限时滚动。阶段气泡继续使用右侧图标和会话区域以外的剩余空间。

修正版在隔离数据和屏幕外窗口中，通过216组布局组合、1532项布局/滚动断言；相关提示布局15项、控件与操作范围30项通过。检查包含短/长中文、英文和混合名称、不同列宽、同一卡片缩放、未绑定阶段、单阶段及灵感库例外。

验证使用本机150% DPI；没有移动鼠标或注入键盘，不操作正式数据、自启或用户当前Codex。真实鼠标及多屏混合DPI未验收。历史球动画离屏检查的未通过结果沿用原记录，不计作本轮通过。
