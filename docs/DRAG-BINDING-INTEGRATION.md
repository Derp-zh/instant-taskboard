## 已跑通路线与保持项

鼠标松开后再次读取真实落点，验证同用户/Session/登记桌面身份，再定位目标自己的会话菜单。当前主聊天操作按钮暴露 ExpandCollapse，复制菜单命令暴露 Invoke；不能统一按 Invoke 调用所有按钮。取得严格本机 `codex://threads/<UUID>` 后调用单阶段绑定及原保存链。读取不依赖观察端口或名称目录匹配，侧栏另一条会话无需打开。

保留以下行为：只在拖出来源列表后隐藏其他原可见列；来源列保留；结束/取消只恢复原可见列，不修改展开标记或永久隐藏配置。名称拖动不启动整卡移动或编辑，单击不改绑；Esc/右键/捕获丢失/来源卸载/整组收起可取消。原会话选择器、卡片和阶段按钮继续工作，背景/裁切/层次/菜单原操作范围保持。

剪贴板在复制前完整物化，复制后核对来源/序号再恢复；期间有其他剪贴板变化则不覆盖。只清理确认仍打开的 Codex 菜单，不在菜单关闭后盲发 Esc。获取失败、错误目标、远程 host 不支持或目标变化时不猜编号，保留原绑定并说明原因。不向 Codex 投放文件、输入文字或发送消息。

改绑只影响来源阶段，保留未提交编辑及其他阶段；新绑定不继承旧请求、等待保护或来源 epoch，同编号改名称不清有效保护。准确保存失败反馈，支持撤销，并验证后续旧编辑保存不会覆盖最新绑定。

## 实施顺序与验收

1. 核对真实主开发基线、工作区和清单差异，先读权威规则；列出共享消费者、保持项及本轮回归选择。将模块合入目标缺失位置，拆开业务与测试模式。
2. 普通主开发构建，不带 `--drag-binding-preview` 或测试版本号，以新的隔离 `--data-dir` 启动。通过测试夹具准备任务，验证普通功能可用、默认路径逻辑未被改写、正常启动不自动创建示例或测试托盘标识。
3. 适配并运行有区分力的规则/保存/控件检查，重跑阶段隔离、改绑代次、旧等待、编辑合并、撤销及落盘回读。回归跨重连多阶段等待优先、旧终态隔离、解绑重绑/归档恢复、真实恢复和红点规则。
4. 当轮重新协调鼠标和临时剪贴板操作，开始前提示。先检查输入落点属于自己启动的隔离测试窗口，目标属于原 Codex；遮挡则停止，不点击遮挡应用。分别真实拖到侧栏当前会话、另一条未打开会话、当前正文，独立核对准确编号、来源阶段、实际文件及重开保持。
5. 验证离开来源边界的时机、原先隐藏列不弹回、成功/失败/取消后的恢复；覆盖错误应用/空白/取消、文字外空白、原整卡拖动/编辑/会话选择器及阶段按钮。涉及共享输入的改动按项目要求补列表空白右键、标题拖动、缩放、新建轮廓和滚动条，系统命中、内部命中、真实动作分别报告。
6. 剪贴板验证文字/HTML，多格式不完整缓存则明确失败保护；测试结束回读恢复鼠标/前台/剪贴板。原 Codex 不关闭或重启，不发消息、不执行批准；不结束用户进程，只清理自己启动的隔离测试进程。
7. 构建到新独立目录，核对源码与实际测试包，提供启动入口、包完整性和本轮验收。运行文件不覆盖、正式数据和配置不搬迁、测试任务不导入。不以 r2 历史数量充当新包通过数量。

尚未全面验收的边界：同名会话实机、多 Codex 窗口/分屏、混合 DPI、远程 host、快速目标变更及自定义剪贴板格式。应按实际支持范围验证和报告；无法准确定位时保留原绑定，不静默猜选。绑定成功与 Codex 观察/问题/批准/恢复的完整生命周期分别说明，不扩大既有能力宣称。
