# Codex 初始化与兼容说明

0.9.22 提供首次提示与“设置 → AI平台接入 → 初始化AI平台配置”，可一键初始化、重新检查及手动选择桌面端/CLI。用户无需运行项目脚本或填写环境变量。

程序优先沿用有效旧路径，经 Windows 安装登记及实际位置发现安装，不写死带版本号的路径。桌面程序用于打开原 Codex，CLI 用于聊天目录；身份、版本、完整观察源及具体聊天能力分别报告，目录成功不代表完整监测。

当前只接受固定观察兼容 profile 26.1013.4894.0，并检查原安装身份、同用户/会话、监听来源、准确模块哈希。已只读核验的 26.1016.6573.0 结构有变化，仍显示“当前版本暂不兼容/待完成”，不猜未知对象、不修改安装文件、不自动降级。新版本需要另行核验后才能接入。

若兼容版本需要观察启动参数，先由用户自行退出 Codex，再点击界面中的确认打开。仍在运行则不启动另一实例；看板不会强制结束、重启或打断正在使用的 Codex。未经主动确认保留待完成。

初始化不选择、创建或接管聊天，不发消息、不代答、不批准。用户在任务阶段内搜索并选择已有聊天。连接已准备好与具体聊天已验证分开显示；不发送测试指令验证。

真实执行才进入进行中；问题、批准等待、整轮结束/失败/停止进入待操作；回答或批准本身不算恢复。多阶段等待优先，断线/Unknown不清已确认等待。真实整轮失败/额度停止、完整Plan恢复仍有待原桌面专项验收。

详细操作见[0.9.22使用说明](USER-GUIDE-0.9.22.md)，本轮实际验证见[公开验收](ACCEPTANCE-0.9.22-PUBLIC.md)。源码中保留的历史探测/启动工具不再是普通用户的配置步骤。
