# Codex连接与状态观察

设置 → AI平台接入 → 初始化AI平台配置，点击一键初始化／重新检查。无需项目脚本、环境变量或手填参数。默认已有Codex安装，当前仅支持Codex。

先实际尝试只读连接，不按版本号或固定exe哈希整体拒绝。有效手动路径与原服务地址保留；商店升级后的失效安装路径按系统登记更新并备份。界面分别报告聊天搜索、原桌面实时连接、提问／批准观察和具体聊天测试，不把目录可读当完整监测。

在任务阶段选择已有聊天后，可点“测试已关联聊天”，只读准确绑定的当前状态与请求集合。没有绑定时说明如何选择；不会自动创建聊天、发测试消息、回答或批准，不改变任务状态。当前空闲或一次读取不代表提问／批准／实际恢复全流程已经验证。

状态观察是可选的本机只读桥，并非Codex官方稳定API。只接受经身份验证的本机原桌面、同用户/Windows Session、准确监听PID、唯一主页面及已核实模块内容。保留Hfn/Dot旧合同，新增26.1016.8120.0的imn/nct合同；版本号不作连接门禁，未知模块不发送猜测对象表达式，只提示观察暂不支持，基础连接仍分项报告。

当前本机26.1016.8120.0：系统登记、有效OpenAI签名、CLI、目录与原桌面只读通道通过；9339无监听，运行时对象及原桌面提问／批准／恢复未验收。新适配的静态合同、合成协议与投影检查不能冒充原桌面生命周期通过。

提示“Codex已连接，完整状态观察待开启”时，可继续普通看板使用。方便时自行保存工作并退出Codex，再点击“打开Codex并开启状态观察”，主动确认后打开；看板不会擅自退出、重启或修改安装文件。普通重开可能不带观察参数，重新检查会显示实际缺项。

只保留结构化ID/类型/轮次/完整性/执行布尔值，不根据聊天正文或UI文字猜状态，不保存问题、答案或令牌。断线/未知不清除已确认等待；回答／批准本身不等于执行恢复。真实整轮失败、额度停止及Plan完整恢复仍保留专项验收缺口。
