# Codex会话状态观察说明（公开版）

本功能是可选的本机观察桥，不是Codex官方API，也不是通用AI接入。普通看板启动时默认关闭；只有用户手动运行包内`启动观察.ps1`，且兼容的Codex已开放本机调试入口时，才启用会话状态读取。

当前针对OpenAI Codex 26.1013.4894.0验证。需要PowerShell 7。观察端口默认为`127.0.0.1:9339`。Codex普通重开后该入口可能关闭；版本或接口变化后观察功能可能停用，不能承诺自动兼容所有更新。

桥接只读取有限的结构化请求/运行状态信号，不读取聊天正文来猜测状态。它不会代答、批准操作、发送消息或替用户执行Codex任务。已确认的等待状态在连接暂时不可读时会保留。

目前有真实桌面证据的范围包括等待用户回答、Plan问题等待以及人工批准后恢复执行等流程。真实整轮执行失败和额度耗尽停止的原桌面验收尚未完成，不能视为已验证能力。历史验收摘要见[0.9.19功能范围](ACCEPTANCE-0.9.19.md)。
