# 旧任务面板拆解记录

日期：2026-10-12。分析目标是提取新版可借鉴的功能机制，随后清理旧程序，从零重写。

## 1 分析依据与边界

删除前读取并记录20个源码、配置和检查脚本文件，共2453行；使用Codebase Memory结构、方法与调用关系核实入口，以本地源码摘录及SHA256记录补充新鲜度检查。完整文件清单见 [来源清单](evidence/source-inventory.json)。

源码与清理前Git提交`5bed7c9c7865c963f2d2b52da48c7bb2852373f6`一致，没有未提交的旧源码变化。旧可运行版、交付包和源码构建的程序集哈希不同，因此用REA做了执行无关的程序集身份与成员比较。结果与限制见 [运行包证据](REA-FINDINGS.md)。本轮未启动旧程序或操作用户鼠标。

先前已通过的20项规则自测另存 [20261012规则自测](evidence/20261012规则自测.txt)。本轮没有把旧测试重新当作新版验收，也不宣称完整观察了各旧运行包的现场行为。

## 2 旧程序的实际职责

| 部分 | 旧职责 |
| --- | --- |
| App | 读取本地数据、互斥启动、创建悬浮球托盘、提醒计时、保存和退出 |
| BoardWindow | 作为不显示的业务协调窗口，构建各列卡片、筛选、编辑入口、拖放、设置和备份 |
| ColumnWindow | 每分组一个独立顶层窗口，标题区移动、右下角拉伸、阻止普通关闭 |
| Workspace | 默认工作区布局、位置注册、整组开关、恢复默认、邻列压缩、吸附参考线 |
| WindowMotion | 共享时钟的缩放回弹与反转，不是新版向下拉出 |
| WindowMover、GuidesWindow | 移动时鼠标位移、取消恢复、对齐虚线和吸附 |
| TaskEditor、StageEditor | 模态编辑内存副本、步骤和AI会话阶段、打开外部链接或应用 |
| Models、Logic | 稳定任务/分组编号、移动排序、模拟AI事件规则、提醒周期计算 |
| Store | JSON原子写入、导入校验、损坏原件保留和备份恢复 |
| Native、Theme、Ui | 系统窗口、DPI、毛玻璃、圆角裁剪、颜色资源与通用控件 |
| SelfTest、DesktopCheck | 隔离数据验证、桌面靶窗、自动鼠标检查和截图 |

## 3 主要调用链

1. 启动 → Store读取 → Theme应用 → 创建协调器/球/托盘 → 展开窗口 → 提醒调度。
2. 球或托盘单击 → ToggleBoard → ShowWorkspace/Hide → Workspace.ShowAll/HideAll → WindowMotion。
3. 新建/编辑 → TaskEditor复制任务 → 修改内存副本 → Save提交 → Store.Save → 球计数与全部看板刷新。
4. 卡片拖动 → 携带任务编号 → 目标卡片/列表Drop → Logic.Move → 保存 → 排队刷新。
5. 每10秒提醒 → Logic.Tick → 标记待处理并推进周期 → 保存 → 系统通知。
6. AI事件 → Logic.ApplyEvent去重和流转；实际入口只有自测，未接入客户端/CLI。

图结构快照见 [架构导出](evidence/architecture.json)，所有181个旧Method节点见 [方法索引](evidence/method-index.json)。工具中部分重复Field/Variable节点是图表示，不能当作源码真的重复定义。

## 4 主要可借鉴成果

独立窗口避免一整块透明窗口占住列间缝隙；托盘生命周期让界面隐藏时后台仍活着；共享动画状态支持快速反转；位移前快照支持取消；稳定任务编号支持拖放；原子写入避免半文件；周期提醒只补一次；编辑副本避免未保存输入立刻污染任务。

这些思想均需适配新版，不能将旧名称、参数、阶段模型或旧外部点击规则一并照搬。逐任务边界见 [功能对应表](FEATURE-MAP.md)，写法见 [重写思路](../REWRITE-IDEAS.md)。

## 5 旧问题与新写法要求

| 观察 | 证据及范围 | 重写时处理 |
| --- | --- | --- |
| 重建内容会重复给持久窗口注册Esc监听 | E08、E29，静态确认；未实测长期内存增量 | T26只注册一次或正确解除 |
| 一项变化重建六列且全部卡片常驻 | E16、E28、E29；历史布局约2秒 | 增量更新、可见项创建 |
| 操作反馈TextBlock没放进界面 | BoardWindow.summary/status，源码静态确认 | 保存成功/失败使用可见反馈 |
| 导入未完整检查空字段和空步骤 | E21，之前补充运行已复现空引用 | T24校验完整对象与引用 |
| 稍后提醒不能压住原定到期 | E18，之前补充运行已复现 | 若保留此功能，先定计划优先关系 |
| 整体替换任务只特殊合并提醒 | E14，AI后台更新未来可能覆盖 | T25只提交用户改动字段 |
| 事件去重不含会话 | E19；之前补充运行复现同平台相同ID冲突 | C03按真实会话执行标识去重 |
| 详情阶段等于AI会话 | E11，数据结构明确 | 新版分开两种数据对象 |
| 拖动自动滚动未严格限定纵向有效落点 | BoardWindow.AutoScroll，静态边界风险 | 只滚动当前落点列 |
| 异常捕获继续运行可能留部分内存修改 | App未处理异常处理器，静态风险 | 修改提交有完整边界，保存失败保持可恢复输入 |
