# 0.9.6本地桌面验收（2026-10-16）

四项需求实现及隔离验收完成：全屏后台原始鼠标输入/跨来源去重及输入归属判断；球、列表和悬浮排除Alt+Tab；首个编辑居中、后续32/32，设置和新建重新打开居中；单列按当前整组缩放基准恢复，球/托盘/设置恢复整组原始默认大小和位置。整组收起恢复保留同一窗口、位置和输入。

- 16项不可见布局/配置/输入登记/样式及82项控件回归通过；22项完整桌面布局和4项繁忙外点通过，界面阻塞1700ms仍能收起恢复。
- 关闭普通鼠标钩子后，独立全屏窗口禁用旧鼠标消息、隐藏鼠标并捕获输入，5项检查通过。核对它确为前台且拥有捕获，同时光标命中的是隔离看板；RawPresses=2、HookPresses=0，仍能收起并恢复同一窗口及输入。这是受控桌面输入模拟，未直接操作第五人格或崩坏三。
- 实际Alt+Tab画面核对无隔离看板条目。系统XAML视图的UI自动化接口返回0元素，因此不以空匹配作成功依据，而以保存的实际画面人工核验。看板目录文件夹仍是资源管理器窗口。截图含桌面内容，属于私有test-output，不公开。
- 最终verified包6项卡片/空白/标题双击及32/32实际错位检查通过。退出系统切换遮罩后等待350ms再点击，避免测试本身覆盖落点。失败诊断保留，不计为通过。

最终新增的仅隔离验证入口、诊断和工具，正常输入/布局/样式实现不变；16/82/22/4报告来自此前local构建，5项全屏模拟与6项手势及Alt+Tab来自最终verified构建，不冒充所有报告DLL逐字相同。用户已协调，鼠标与原前台恢复、Alt释放，只停止自己创建的隔离进程；正式数据、用户旧进程及实际游戏保持。
