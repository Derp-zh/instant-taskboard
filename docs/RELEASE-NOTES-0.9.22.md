# 即时任务看板 0.9.22

本版包含阶段删除、六个内置列表保护、设置排版优化和悬浮球提示交接调整，并合入此前未公开发布的 Codex 初始化功能。

- 新建/编辑的阶段名称右侧新增圆形 X；保存后删除，禁止删除最后一个阶段和唯一运行阶段。
- 六个内置列表均不可删除，保留隐藏/改名；自定义列表清空后仍可删除。旧已删除的三类内置列表恢复为隐藏。
- 设置按用途分组，保留全部功能与选项；新增“保存设置”入口，原自动保存和即时生效保持。
- 球从边缘弹出时，红点完全消失和数字开始显示在同一帧交接；数字预先布局，原位移/菜单/命中范围保持。
- Codex 首次初始化可稍后，从设置可重检/修复；自动区分桌面端与 CLI，沿用有效旧配置，提供手动选择和诊断，不要求运行脚本。

## 使用

下载 ZIP，完整解压，运行“即时任务看板.exe”。包含 .NET，无需另装运行时。升级前请从旧看板托盘退出；保留实际任务和配置目录。运行包内附使用说明、兼容说明和验收边界。
