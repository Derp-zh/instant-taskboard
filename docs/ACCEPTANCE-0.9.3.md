# 0.9.3 本地修订与速度比较验收

日期：2026-10-15。范围：PRD第27节U79至U85/A97至A103、T101至T108。普通本地交付，公开版本仍为0.9.1。

## 交付效果

- 暂存卡片只补上下圆角两处缺口，主体不重复叠底色；透明度50%的真实屏幕补口和旧竖条位置已核实。
- 虚线新建轮廓向左20单位，触发起点保持，右侧裁掉20单位；编号与前台X均为48×40亮色白边胶囊，仍只是编号。
- 新建/编辑的新阶段按钮只横向移到最左，纵向不变。
- 所有悬浮窗口采用同一100ms中央画卷及纵向白芯泛光，首次打开/关闭编辑、设置、通用窗口均实际采样；球和列表保留各自的动效。
- 最新确认规则：点击其他应用立即整组收起，保留当前悬浮窗口和输入，展开恢复同句柄和最后输入；看板内部、悬浮窗口外单击保持，快速双击只关闭最上层悬浮窗口，设置同规则。关闭窗口导致的焦点变化不触发额外收起。
- 两份完整程序：原速360ms，1.35倍约266.67ms。仅暂存抽牌各阶段同比缩短，路径、图层、无纵移、开合与功能相同。常用速度待用户比较决定，快版不自动替换启动登记和快捷方式。

## 验证

原速与快版各76项控件/手势检查通过；45画卷及冷启动白条、77完整窗口（300任务及草稿、搜索/保存/提醒/拖动/路径与60秒空闲）通过。122规则引用0.9.2已通过报告，两版核心DLL与原包的SHA256完全一致，明确作为复用证据。

真实鼠标验证经用户协调，整组隐藏与恢复、设置同句柄、新建最后输入、看板内单击/双击、慢速/远距离两次及重复调用通过；四类背景采样最大RGB差值和均0，结束恢复鼠标和焦点。未经有效落点的失败检查保留，未算通过。

真实透明度50%时，旧竖条处与主体采样差值和4，上下补口均未暴露背景。原速/快版53/51次抽牌屏幕采样，完成交接21/24次，最大差值和均7，宿主句柄、位置、恢复尺寸及不隐藏核实；准备与动作耗时分开记录。球展开宽度单调，在UI忙碌时继续呈现中间画面。详见[验证摘要](VERIFICATION-0.9.3.json)。

此前固定等待和两次GDI截图可能过早判断关闭、漏掉短暂白条，已修正为等实际状态及一次取同行/列。真实失败促成原圆形保护、首次合成提交及截止时序修复，失败文件保留。有限采样不构成所有硬件/负载下的绝对无闪烁或恒定120帧保证。
